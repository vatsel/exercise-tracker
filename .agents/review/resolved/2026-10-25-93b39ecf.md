## Changes

- **New Scripts bullet after the Dev server bullet: how to write and run a TypeScript script in `scripts/`.**
  - Detour: the agent wrote `scripts/hash-password.ts` importing `../src/lib/password.ts`. `tsc` failed with
    `TS5097: An import path can only end with a '.ts' extension when 'allowImportingTsExtensions' is enabled`,
    so it added that option to `tsconfig.json`. Running the script then printed
    `[MODULE_TYPELESS_PACKAGE_JSON] Warning`. The agent renamed the script to `.mts`, but the warning came
    back, this time from `src/lib/password.ts`. It finally used `node --no-warnings` for the password change.
    That cost three extra rounds for something a future script will run into again.
  - Verified fact: Node is v22.21.0 and runs `.mts` directly. `package.json` has no `"type"` field, so any
    `src/*.ts` a script imports still triggers the warning. `node --no-warnings scripts/hash-password.mts x`
    prints a clean `scrypt:…` hash. `tsconfig.json` (working tree) has `"allowImportingTsExtensions": true`,
    and `npx tsc --noEmit` passes.
  - Verified in: `node --version`, `package.json`, `tsconfig.json`, `scripts/hash-password.mts`, and running
    the script with and without `--no-warnings`.
